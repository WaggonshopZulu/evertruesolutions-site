Chronicle Email: Privacy Policy

Last updated: October 15, 2026

Chronicle Email is a personal tool that organizes the email in one person's own Gmail account. It is operated by Andrew at Evertrue Solutions and is not offered to the public.

What it accesses

With the account owner's permission, it reads email messages and settings (gmail.readonly) and applies labels and archives messages (gmail.modify). It never permanently deletes email.

How the information is used

Message information is used only to produce a summary report and to apply the labels and archiving the account owner approves. It is not used for advertising or profiling.

Where it is stored and what is sent elsewhere

The tool runs on the account owner's own computer. Sign-in tokens and generated reports are stored only on that computer. Message bodies and attachments are never sent anywhere. To sort mail into categories, the tool sends only each message's date, sender and subject line to Claude, an AI service operated by Anthropic, and receives back a category label. This information is used only to sort the account owner's own mail.

Sharing

Apart from the Anthropic request described above, no information from your Google account is disclosed to anyone else. It is not sold, and it is not used by this tool to train AI models.

Google API Services User Data Policy

Chronicle Email's use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the stored tokens on the computer also ends access.
